从远处看，最能说明星环有多宽的，是中间那条细黑线。镜头压低后，线条慢慢张开，近处的碎石掠过画面下沿，远处的环仍亮着。做穿环镜头时，我把画面停在中途。左右两边都有参照物的那一瞬，才第一次觉得自己确实在其中。

## 给空白一个地址

我把环面分成几条互不相接的半径区间。先选中一条环带，再在它的内外边界之间撒点，这样空隙有确切的位置。拿本场景中相邻的两条带做例子，单位是模型坐标。

| 区域 | 半径范围 | 从镜头里看到什么 |
| :--- | :--- | :--- |
| 内侧亮带 | 4.68 至 5.10 | 密集的细粒，轮廓较亮 |
| 环缝 | 5.10 至 5.22 | 少了近景粒子，可以透见背景 |
| 外侧环带 | 5.22 至 5.75 | 颗粒重新聚拢，边缘有层次 |

标点落在 5.16，正好在缝中央。把它绑在一个粒子上，标点就会偏向缝边。我把它固定在星环的局部坐标里，再让它随环面转动，探测器看到的就始终是同一道空隙。

## 抽半径时，先想一想面积

在半径上均匀抽样，外圈和内圈每增加同样的宽度会分到相近数量的颗粒，可外圈的周长更长，视觉上就更稀。如果目标是让环带每一小块面积获得近似相同的采样机会，可以先抽平方半径。

~~~js
const r = Math.sqrt(inner * inner + u * (outer * outer - inner * inner));
const x = r * Math.cos(angle);
const z = r * Math.sin(angle);
~~~

其中 `u` 在零和一之间均匀分布，方位角覆盖整圈。再给高度一个很小的离散量，贴着环面飞时，石粒就不会同时消失成一条线。

## 穿过去之后，再回头

环缝和投影都可能看成一条暗带。稍稍换个视角，区别就出现了。空隙一直跟着环带，行星投下的阴影却由光源方向决定。把镜头移过两者交会的位置，看原先隐在阴影里的碎石一颗颗亮起来，最容易分清这两个结构。
